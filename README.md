# Ovhan Global Website

## Files
- `index.html` — the main website file. Keep this file at the root of your website project.

## Preview the website
1. Download `index.html` to your phone or computer.
2. Open it with a web browser to preview the page. Some browser features may work differently when opened as a local file.

## Publish using GitHub and Cloudflare Pages
This project has previously been connected to GitHub and Cloudflare Pages.

1. Keep a backup of your current working website before replacing anything.
2. Open the GitHub repository connected to your Cloudflare Pages project.
3. Open the existing `index.html` file and choose the edit option, or upload the new file to the repository root.
4. Replace the old contents with the contents of this `index.html` file, or upload it as `index.html` and confirm replacement.
5. Commit the change to the branch used by your Cloudflare Pages project (often `main`).
6. Open Cloudflare Pages and check the deployment status. Wait for the deployment to complete, then open the site's domain and test it on mobile.

If your Cloudflare project uses **Direct Upload** instead of a GitHub connection, upload a folder containing `index.html` at its top level, following the upload options shown in your dashboard.

## Important notes
- The product catalogue and prices are sample content and should be reviewed before launch.
- Any currency conversion values shown on the page may be illustrative; confirm the current exchange rate before relying on them.
- The shopping cart and WhatsApp ordering are browser-side features. This file does not by itself provide a secure server, customer database, inventory system, or real online payment processing.
- Do not publish payment credentials, passwords, private keys, or other confidential information in the HTML file or a public GitHub repository.
- Test the menu, search, product cards, cart, WhatsApp link, and layout on a phone before sharing the website with customers.

## Before accepting real orders
Set up and test a reliable order-management process, accurate delivery and return information, and a trusted payment provider. Never collect or store customers' card details directly in this static HTML page.

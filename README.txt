OVHAN GLOBAL CUSTOMER STOREFRONT – HOMEPAGE CLEANUP UPDATE

PACKAGE CONTENTS
- index.html: updated customer storefront
- README.txt: this file

CHANGES IN THIS UPDATE
1. Reduced the dropdown menu width to a compact 218px on larger screens and 210px on mobile (subject to the available screen width).
2. Removed the homepage hero copy and panels: “Discover More. Shop Smarter.”, “Explore Products”, “Find your next favourite”, “Everyday style. Easy choices.” and “Questions before you buy?”.
3. Removed the separate “Special offers & seasonal finds” promotional strip.
4. Kept the advertisement slideshow as the main promotional area near the top of the homepage. Its current sample slides and navigation remain in place for now.
5. Preserved the existing Ovhan Global logo and branding, product catalogue, featured products, mobile navigation, account pages, Supabase integration, cart and order functionality.

ADVERTISEMENT MANAGEMENT – NEXT STEP
The customer slideshow remains in place, but this package does not yet add admin controls for creating advertisements. In the next step, the separate private admin website will be updated so authorised administrators can add, edit, publish and remove slideshow advertisements. The customer slideshow can then display those published advertisements.

TESTING NOTES
- This is a front-end update and has not been live-tested against your Supabase project.
- Back up the currently deployed customer index.html before replacing it.
- After deployment, check the dropdown width, homepage slideshow, featured products, sign-in, account, cart and order history.

DEPLOYMENT
1. Keep a backup of your current customer storefront.
2. Replace the customer website index.html with the index.html in this ZIP.
3. Do not change your Supabase URL, anon key, SQL tables, policies or storage buckets for this update.
4. Open the website on your phone and confirm the removed promotional panels are gone and the slideshow remains visible.

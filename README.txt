OVHAN GLOBAL WEBSITE UPDATE
===========================

FILES
-----
Ovhan_Global_updated.html
  Updated website HTML file. Use this file in place of your previous index.html
  (rename it to index.html if your hosting setup expects that filename).

CHANGES INCLUDED
----------------
1. Language selection updates the main website interface across the translated
   sections included in this version.
2. The separate visible "Add Image" option was removed.
3. A camera button was added at the lower-right of the circular profile photo
   to open the existing profile-picture editing/upload flow.
4. The profile heading displays the signed-in account holder's name.

INSTALLATION
------------
1. Download and extract this ZIP file.
2. Back up your current website HTML file.
3. Upload Ovhan_Global_updated.html to your website, replacing the existing
   index.html (or rename the downloaded file to index.html first).
4. Keep your existing Supabase project settings and configuration unchanged.
5. Open the website and test language switching, menu navigation, products,
   profile name, and profile-picture editing.

NOTES
-----
- JavaScript syntax was checked, but a complete live browser/end-to-end test
  was not performed.
- Seller-entered product names and descriptions are not automatically
  translated by this update; they require multilingual product data or a
  translation service.
- Keep the backup until you have tested the updated site successfully.
